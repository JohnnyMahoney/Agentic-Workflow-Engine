# Section 3.4 safety verification

Current regression evidence uses synthetic values, local HTTP fixtures and real
Chromium. Discovery SDK tests use scripted responses and simulated operators.
The automated logs below are distinct from the [final genuine Claude E2E](final-live-e2e/README.md),
which passed Discovery -> separate Compilation -> validation -> fresh Replay with
the current policy. That final lookup required no human intervention.

- [Build](build.log)
- [Main regression tests](tests.log): 50/50 passed at the initial completion run.
- [Final focused safety/handoff verification](focused-final.log): 16/16 passed after diagnostic-event updates.
- [Banking Sandbox](banking-tests.log): 12/12 passed, including happy path,
  parameterized lookup, permitted creation, business refusals, slow load, timeout,
  permission/session failure, unexpected dialog, ambiguity and uncertain writes.
- [Banking scenario diagnostics](banking/README.md): structured results and sanitized
  DOM diagnostics replace newly persisted raw screenshots.

Focused safety tests prove: blocked origins/routes/redirects produce no request to
the forbidden destination; unknown/blocked/unapproved risky mutations have zero
side effects; narrow trusted risky permission works; Discovery and Replay enforce
policy independently of the artifact's readOnly claim; secrets in DOM, URL and tool
responses do not appear in captured text; binary screenshots are refused; missing
or sensitive data classification stops execution.

Confirmed fixes include secret echoes in unstructured sibling fields, trusted
fixture policy migration, pre-dispatch mutation accounting, and using one elapsed
sample for timeout logging/decision consistency. Original failing regression logs
are retained as `initial-regression.log` and `second-regression.log`.

The Banking verification used an isolated bundled server on port 8093:

```powershell
node scripts/serve-banking-sandbox.mjs --port 8093
# In another terminal:
$env:BANKING_SANDBOX_URL = 'http://localhost:8093/modern.html'
$env:RUNTIME_EVIDENCE_DIR = 'evidence/safety-3-4/new-banking-run'
npm.cmd run test:banking
```

Temporary per-test fixture evidence is generated by node:test in the OS temp
directory unless a test-specific evidence directory is supplied. The retained
banking evidence is under this directory. See [guarantees and limitations](../../docs/safety.md).
